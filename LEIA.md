# ADS-1-semestre

Repositório com exercícios e atividades da faculdade (Análise e Desenvolvimento de Sistemas), 
disciplina de Algoritmos e Lógica de Programação em C.


## Como compilar

Os códigos foram feitos em C e testados no Code::Blocks.  
Para compilar com GCC, por exemplo:

```bash
gcc -o programa programa.c
./programa
```

## Observações

- Alguns códigos foram desenvolvidos como atividades em grupo na faculdade e foram adaptados para fins de estudo.
- Este repositório serve como registro do meu aprendizado no primeiro semestre.
